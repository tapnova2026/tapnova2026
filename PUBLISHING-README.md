# Publishing the TapNova Roadmap

All public-facing assets in this bundle are written in English.

## GitHub Pages website

Add these files to the root of the `tapnova2026/tapnova2026` repository:

- `roadmap.html`
- `roadmap-cover.svg`
- `robots.txt`
- `sitemap.xml`
- `README.md`

Before adding `robots.txt` or `sitemap.xml`, check the repository for existing versions and merge the roadmap URL instead of replacing existing entries. Add a visible link to `roadmap.html` from the home page. The canonical roadmap URL is `https://tapnova2026.github.io/tapnova2026/roadmap.html`.

## Google Search

After the page is live, verify the GitHub Pages site in Google Search Console. Submit `https://tapnova2026.github.io/tapnova2026/sitemap.xml`, inspect the roadmap URL, and request indexing. Google may take time to crawl or index a new page, and submission does not guarantee ranking or inclusion.

## YouTube

Use the title, description, tags, script, shot list, pinned comment, and thumbnail text in `TapNova-Roadmap-Publishing-Pack.md`. Upload the finished video and set `roadmap-cover.svg` or an exported PNG version as the thumbnail. Confirm all dates and token allocation figures before publishing.

## Telegram Community

Post the English Community copy in `TapNova-Roadmap-Publishing-Pack.md` at `https://t.me/TapNovaCommunity`. Link to the public roadmap page after GitHub Pages deployment completes.

## Final content check

The supplied workbook is a planning draft. Confirm the 100 billion TNV supply, allocation percentages, 24-month vesting interpretation, airdrop target dates, and planned product milestones with the project owners before posting publicly.
